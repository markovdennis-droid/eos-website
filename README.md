# Eos — один сайт для всех устройств

Одна главная страница index.html содержит все функции. Нет отдельной страницы приложения и отдельных версий Android/iPhone.

Возможности: космический фон и вращающийся зодиак, полные общие/любовные/рабочие прогнозы и советы, календарь, три языка прогнозов (RU/EN/ES), сохранённые записи, совместимость, сонник Миллера. Интерфейс и сонник остаются русскими; английский оригинал сонника доступен отдельно.

## Запуск

Загрузите содержимое eos-website на статический HTTPS-хостинг. Откройте его адрес. На iPhone: Safari → Поделиться → На экран Домой. На Android: Chrome → Установить приложение / Добавить на главный экран. Eos откроется отдельным окном с теми же функциями и содержимым. Платформа может предлагать установку иначе в зависимости от браузера.

Для просмотра с компьютера можно открыть index.html. Автономный Eos.html содержит все ресурсы внутри, но служит для просмотра; для установки и офлайн-режима нужен комплект файлов на HTTPS. Сохранённое хранится в конкретном браузере и не синхронизируется автоматически между устройствами.

## Состав

index.html — единый интерфейс; style.css — оформление; app.js — функции; horoscope-data.js — годовые банки на трёх языках; miller-data.js и miller-original.txt — сонник; assets/ — изображения; manifest.webmanifest и sw.js — установка и офлайн-кэш. При обновлении увеличивайте версию кэша в sw.js.

## Статус

Приём платежей и серверная защита доступа не подключены. Эта версия содержит открытые банки текстов и пока не предназначена для продажи защищённого доступа. Нативных APK/IPA нет: это устанавливаемый сайт.

Материалы перенесены из Horoscope 10. Годовые тексты повторяются; в русских любовных банках есть исходные повторы. Индексы и обработка високосного года сохранены: 366-й день использует первую запись. Фаза Луны приблизительная; центральная иллюстрация декоративная.

Проверены синтаксис, локальные ссылки, целостность архива и 105264 сочетания даты/знака/темы/языка для 2026 и 2028 годов. Установка на физические iPhone/Android и последняя визуальная версия отдельно не проверялись.
